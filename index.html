CréditTrack PRO ne contient aucun cookie publicitaire (pas de Google Ads, pas de Meta Pixel, pas de revente de données). Vos données restent 100% privées.

1. Données Collectées par l'Application

Dans le cadre de votre utilisation de CréditTrack PRO, seules les données nécessaires au suivi commercial sont traitées :

  • Votre Compte Commerçant : Nom de boutique, adresse e-mail professionnelle, numéro de téléphone, mot de passe sécurisé (haché par Argon2/Bcrypt).
  • Vos Fiches Clients & Dettes : Nom du client, numéro WhatsApp/téléphone (utilisé pour les relances automatiques), montant des créances, dates limites de règlement et historique des encaissements.

2. Finalité du Traitement

Vos données sont exclusivement utilisées pour :

  • Assurer l'enregistrement comptable de vos ventes et le calcul des soldes dus.
  • Permettre l'envoi de messages de rappels sur WhatsApp et SMS vers vos clients.
  • Générer des reçus PDF de paiement personnalisés avec signature.

3. Hébergement & Sécurité

Vos informations sont stockées dans une base de données PostgreSQL hébergée sur Supabase avec chiffrement au repos (AES-256) et transit sécurisé (HTTPS TLS 1.3). Chaque commerçant est isolé de manière étanche grâce aux politiques Row Level Security (RLS) : aucun autre utilisateur ne peut accéder à vos données.

4. Vos Droits (Accès, Export & Suppression)

Conformément aux réglementations sur la protection des données personnelles (RGPD et lois nationales africaines de protection des données APDP) :

  • Vous pouvez exporter l'intégralité de vos données en format JSON ou CSV (Excel) à tout moment depuis les Paramètres.
  • Vous pouvez demander la suppression définitive de votre compte et de toutes vos données associées sur simple demande au support.
Architecture de Sécurité Multi-Tenant RLS

Chaque requête vers la base de données est automatiquement filtrée au niveau du serveur PostgreSQL avec auth.uid() = user_id. Vos données restent strictement invisibles pour les tiers.

  • ✓ Chiffrement de bout en bout : Flux HTTPS chiffré TLS 1.3 avec HSTS activé.
  • ✓ Mots de passe renforcés : Validation stricte (12 caractères, majuscule, minuscule, chiffre, symbole).
  • ✓ Protection anti-intrusion : Rate limiting anti-brute force sur les routes d'authentification.
  • ✓ Stockage Local Offline-First : IndexedDB sécurisé partitionné par identifiant commerçant.
